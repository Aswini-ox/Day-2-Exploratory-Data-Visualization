- Pandas
- NumPy
- Matplotlib
- Seaborn

## Visualizations Created

1. **Correlation Heatmap** – Identifies relationships between numerical features.
2. **Distribution Curves** – Analyzes passenger age and ticket fare distributions.
3. **Scatter Plot** – Visualizes the relationship between passenger age and fare based on survival.
4. **Survival Analysis** – Compares survival outcomes across passenger classes.
